## 主题匹配规则

`detect_theme()` 函数根据标题和标签中的关键词匹配主题：

| 主题 | 触发关键词 |
|------|-----------|
| tech | AI, Shell, API, 代码, 编程, 程序, 服务器, 云, IDE, CLI, Key, 密钥, 模型, Ollama, qwen, GPT |
| hot | 教程, 入门, 实战, 安装, 部署, 上线, 新手, 快速 |
| cool | Docker, 容器, MySQL, Redis, 数据库, 缓存, Portainer, Nginx |
| warm | 对话, 客服, 设计, 生活, 沟通, SSE, 流式 |
| dark | 安全, 黑客, 高级, 硬核, 渗透, 密码 |
| gradient | 时尚, 创意, 爆款, 热门, 推荐 |

## 添加自定义 Emoji

在 `generate_covers.py` 的 `THEME_EMOJIS` 字典中添加：

```python
"tech": [
    ("1f680", "🚀"),
    ("1f4bb", "💻"),
    # 新增：
    ("1f4bb", "🖥️"),  # 桌面电脑
],
```

## 离线使用

如果 CDN 不可用，`<img>` 标签的 `onerror` 会自动隐藏 emoji 装饰，不影响布局。

如需离线使用，可提前下载 SVG 文件到 `assets/emoji/` 目录，并修改 `get_twemoji_url()` 函数指向本地路径。
