## 添加自定义 Emoji

在 `generate_covers.py` 的 `THEME_EMOJIS` 字典中添加：

```python
"tech": [
    ("1f680", "🚀"),
    ("1f4bb", "💻"),
    # 新增：
    ("1f4bb", "🖥️"),  # 桌面电脑
],
```

## 离线使用

如果 CDN 不可用，`<img>` 标签的 `onerror` 会自动隐藏 emoji 装饰，不影响布局。

如需离线使用，可提前下载 SVG 文件到 `assets/emoji/` 目录，并修改 `get_twemoji_url()` 函数指向本地路径。
