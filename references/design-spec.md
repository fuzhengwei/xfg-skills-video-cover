## 视觉要素

### 1. 主标题
- 字号：按平台调整（82/64/56px）
- 字重：900
- 字间距：2px
- 行高：1.05-1.15（按平台调整）
- 高亮词：`transform: rotate(-3deg)` 俏皮旋转
- 每页最多 2 个高亮词
- 阴影：`text-shadow: 0 4px 20px rgba(0,0,0,0.4)`
- 最大宽度：85%-90%

### 2. 副标题
- 字号：主标题的 ~1/3
- 字重：600
- 字间距：1px
- 最大宽度：85%

### 3. 标签栏
- 数量：3-4 个
- 圆角：16px
- 内边距：`6px 18px`
- 背景：主色/副色交替，透明度 0.20-0.25
- 间距：10px

### 4. Badge
- 位置：主标题上方，居中
- 圆角：20px
- 内边距：`6px 18px`
- 背景：主色 0.2 透明度
- 边框：主色 0.4 透明度，1px

### 5. 背景装饰
- **圆形渐变**：2 个大半透明圆（opacity 0.06），左上+右下
- **Emoji 装饰**：2 个 Twemoji SVG（opacity 0.10），左上+右下
  - 使用 `<img>` 标签引用 CDN SVG
  - `onerror` 降级隐藏
  - 尺寸：主标题字号的 0.8-1.1 倍

### 6. 底部栏
- 高度：36px
- 背景：`rgba(0,0,0,0.35)` + `backdrop-filter: blur(4px)`
- 左侧：emoji + 金句（≤15字）
- 右侧：平台名 + 页码

## 间距规范

| 元素间距 | 值 |
|----------|-----|
| Badge → 主标题 | 16px |
| 主标题 → 副标题 | 10px |
| 副标题 → 标签栏 | 16px |
| 标签间距 | 10px |
| 内容区内边距 | 32-40px（按平台调整） |

## 卡通素材规范

### Twemoji SVG
- CDN：`https://cdn.jsdelivr.net/gh/jdecked/twemoji@latest/assets/svg/{codepoint}.svg`
- 协议：CC-BY 4.0（可免费商用）
- 加载方式：`<img src="..." onerror="this.style.display='none'">`
- 透明度：0.10
- 位置：左上 + 右下
