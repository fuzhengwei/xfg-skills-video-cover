# 封面设计规范

## 尺寸规范

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 画布比例 | 16:9 | 与 B站/YouTube 视频封面一致 |
| 最大宽度 | 1200px | 响应式，移动端自适应 |
| 主标题 | 82px | font-weight: 900 |
| 副标题 | 28px | font-weight: 600 |
| 标签 | 15px | font-weight: 700 |
| Badge | 14px | font-weight: 700 |
| 印章 | 80×80px | 圆形，旋转 15deg |
| 底部栏 | 36px 高 | font-size: 13px |

## 字体规范

## 间距规范

| 元素 | 间距 |
|------|------|
| Badge → 主标题 | 16px |
| 主标题 → 副标题 | 10px |
| 副标题 → 标签栏 | 16px |

| 内容区内边距 | 40px |

## 装饰元素规范

### 背景圆形
- 数量：2 个
- 透明度：0.06
- 位置：左上角 + 右下角
- 尺寸：250-400px

### Emoji 装饰
- 数量：2 个
- 透明度：0.08
- 位置：左上 + 右下
- 字号：60-100px

### 印章
- 位置：右上角，距上 30px，距右 30px
- 尺寸：80×80px
- 旋转：15deg
- 边框：3px solid
- 内容格式：`第XX节\n类型`

### 印章类型
| 章节 | 类型 |
|------|------|
| 1-5 | 实战 |
| 6 | 上线 |
| 7-8 | 进阶 |
| 9+ | 完结 |

## 高亮词规范

- 每页最多 2 个高亮词
- 使用 `<span class="highlight">` 包裹
- 效果：`transform: rotate(-3deg)` + 颜色高亮
- 交替使用主色调和副色调

## 底部金句规范

- 字数：≤ 15 字
- 格式：`emoji + 空格 + 文字`
- 透明度：0.5
- 位置：底部栏左侧

## 标签规范

- 数量：3-4 个
- 格式：圆角矩形，`border-radius: 16px`
- 内边距：`6px 18px`
- 背景透明度：0.20-0.25
- 交替使用主色调和副色调

## CSS 变量

封面页面使用 CSS 变量控制主题色：

```css
.slide-bili-cover {
  --bg-color: #1a1a2e;  /* 背景色 */
}
```

通过 `style="--bg-color: #xxx"` 覆盖。
