## 自定义配色

通过 `--bg-color` 和 `--accent-color` 参数自定义：

```bash
python3 scripts/generate_covers.py \
  --title "自定义封面" \
  --bg-color "#1a1a2e" \
  --accent-color "#e74c3c" \
  --platform all
```

或在 JSON 配置中指定 `bg_color`、`accent1`、`accent2`。

支持渐变背景：`--bg-color "linear-gradient(135deg, #667eea 0%, #764ba2 100%)"`
