## 自定义配色

通过 `--bg-color` 和 `--accent-color` 参数自定义配色：

```bash
python3 scripts/generate_covers.py \
  --title "自定义封面" \
  --bg-color "#1a1a2e" \
  --accent-color "#e74c3c" \
  --output cover.html
```

或在 JSON 配置中指定：

```json
{
  "bg_color": "#1a1a2e",
  "accent1": "#e74c3c",
  "accent2": "#f39c12"
}
```
